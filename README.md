# FS27

Juego de fútbol 3D arcade para móviles (Android / iOS), hecho con Unity 6 (URP) y C#.
Proyecto original, inspirado en la simplicidad y el ritmo del fútbol reducido (5 vs 5).

- Arquitectura y decisiones: [`Docs/ARCHITECTURE.md`](Docs/ARCHITECTURE.md)
- Cómo abrir el proyecto y probar la Fase 1: [`Docs/SETUP.md`](Docs/SETUP.md)

## Estado

Fase 1 — Sandbox: movimiento del jugador, sprint progresivo con stamina, balón físico, cámara TV.
